# نبض بورس Native – نسخه اندروید

این پروژه نسخه Native با Kotlin و Jetpack Compose است و رابط کاربری آن WebView نیست.

## امکانات پیاده‌سازی‌شده
- رابط راست‌چین فارسی با Jetpack Compose
- دیده‌بان، افزودن و حذف نماد
- اتصال مستقیم اندروید به API عمومی TSETMC با OkHttp
- قیمت‌ها، اطلاعات حقیقی/حقوقی و جریان پول
- محاسبه RSI و MACD روی تاریخچه دریافت‌شده
- برآورد سطوح حمایت و مقاومت با نقاط برگشت پنج‌روزه
- نمودار خطی بومی با Canvas
- تم روشن و تاریک
- ذخیره نمادها و تم در SharedPreferences
- انتخاب/خاموش‌کردن هشدارهای هر نماد (تنظیم انتخاب‌ها؛ پایش خودکار هشدار هنوز در این نسخه نیست)

## ساخت APK
1. Android Studio جدید را نصب کنید.
2. این پوشه را باز کنید و Gradle Sync را اجرا کنید.
3. در صورت درخواست، JDK 17 و Android SDK 35 را نصب کنید.
4. از مسیر Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی بگیرید.
5. خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نکات و محدودیت‌ها
- این محیط Android SDK و Gradle نصب‌شده ندارد؛ بنابراین APK در اینجا کامپایل نشده است.
- دریافت اطلاعات نیازمند اینترنت و در دسترس بودن API سایت TSETMC است.
- API عمومی ممکن است ساختار یا دسترسی خود را تغییر دهد؛ در آن صورت باید parser به‌روزرسانی شود.
- واگرایی‌ها، ریسک نوسان و پایش خودکار هشدارها هنوز محاسبه/اجرا نمی‌شوند و با برچسب نیازمند داده یا برآورد نشده مشخص شده‌اند.
- داده‌های مالی نمایش‌داده‌شده توصیه سرمایه‌گذاری نیستند.
